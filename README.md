# رزومه آنلاین زینب زحمتی

این پروژه رزومه و پورتفولیوی شخصی من است. در این سایت می‌توانید با مهارت‌ها، سوابق تحصیلی، تجربه‌ها، دوره‌ها و پروژه‌هایی که انجام داده‌ام آشنا شوید.

سایت با HTML و CSS ساخته شده و در موبایل، تبلت و دسکتاپ به‌درستی نمایش داده می‌شود.

## پیش‌نمایش

![پیش‌نمایش رزومه آنلاین](screenshots/portfolio-desktop.png)

## بخش‌های سایت

- معرفی و اطلاعات تماس
- درباره من
- مهارت‌ها
- تحصیلات و تجربه‌های کاری
- پروژه‌های منتخب
- دوره‌ها و گواهی‌ها
- راه‌های ارتباطی و لینک GitHub

در بخش پروژه‌ها، پورتفولیوی شخصی و اپلیکیشن «کنارم» معرفی شده‌اند. اپلیکیشن کنارم یک پروژه گروهی با شرکت فنام است و در حال حاضر روی آن کار می‌کنم.

## ویژگی‌ها

- طراحی فارسی و راست‌چین
- نمایش مناسب در موبایل، تبلت و دسکتاپ
- طراحی Mobile First
- استفاده از Flexbox و CSS Grid
- ساختار استاندارد و معنایی HTML
- بدون نیاز به کتابخانه یا ابزار جانبی

## اندازه‌های واکنش‌گرا

| دستگاه | عرض صفحه | نوع نمایش |
|---|---:|---|
| موبایل | کمتر از `600px` | تک‌ستونه |
| تبلت | از `600px` تا `999px` | گرید دوستونه |
| دسکتاپ | از `1000px` به بالا | نوار کناری و محتوای اصلی |
| نمایشگر عریض | از `1280px` به بالا | فضای بیشتر برای کارت‌ها |

## اجرای پروژه

این پروژه به نصب هیچ پکیجی نیاز ندارد. برای مشاهده سایت کافی است فایل `index.html` را در مرورگر باز کنید.

همچنین می‌توانید در پوشه پروژه یک سرور محلی اجرا کنید:

```bash
python3 -m http.server 8000
```

سپس آدرس زیر را در مرورگر باز کنید:

```text
http://localhost:8000
```
